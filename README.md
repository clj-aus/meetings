## Proposing a talk

Open an issue. Tell us roughly what you'd cover and how long you'd want —
lightning talks are 5–10 minutes, main talks 30–40.

You don't need to be an expert and you don't need a finished thing. "Here's
something I built and here's what surprised me" is a great talk. First-time
speakers get priority on lightning slots.
